# HVAC Study App 1.5

HVAC C-20 bilingual practice application.

## V1.5 changes

- Replaces the V1.4 law bank with 1,408 law questions from `Contractor-Prep_Practice_Questions.xlsx`.
- Keeps the original V1.4 skill bank unchanged.
- Organizes the law bank into seven Topics and 32 sections, with no more than 50 questions per section.
- Preserves English source text and adds reviewed Simplified Chinese translations.
- Tracks completion by law Topic/section or skill chapter.
- Keeps a cross-section mistake review list.
- Displays the supplied code reference with each explanation.

## Data provenance

The English question, answer, explanation, and code-reference fields are sourced from the user-provided workbook. Chinese fields are translations and do not replace the English source of record.
